## 📖 About

🔹 **Terraria — Wing Slot** is a powerful tool built to help you equip wings in a dedicated extra accessory slot in Terraria without sacrificing an existing accessory slot. Wing Slot adds a separate equipment slot for wings, freeing up a valuable accessory slot for rings, emblems, and other items.

🔸 Whether you're a seasoned professional or just getting started, **Terraria — Wing Slot** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Terraria modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Extra Wing Slot | Dedicated equipment slot exclusively for wing accessories |
| All Wings Supported | Compatible with all vanilla and modded wing types |
| Slot Toggle | Toggle the wing slot visibility in the character panel as needed |
| Balance Option | Optional toggle to treat wing slot as a normal accessory for balance |
